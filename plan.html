Chrome Extension for MCQ Generation

Overview

This document provides a comprehensive guide to developing a Chrome extension that extracts and cleans the main content from the active webpage and sends it to a backend server for generating multiple-choice questions (MCQs). The extension integrates with a FastAPI backend that leverages the Groq API to process the content and return MCQs in a structured JSON format.

Prerequisites

  • Basic knowledge of JavaScript, HTML, and CSS.
  • Familiarity with Chrome Extension development.
  • Understanding of REST APIs and backend servers.

Extension Structure

The Chrome extension comprises the following components:

  • manifest.json: Configuration file defining permissions, scripts, and extension metadata.
  • content.js: Script to extract and sanitize webpage content using Readability.js and DOMPurify.
  • background.js: Script to facilitate communication between the content script and the backend server.
  • popup.html: User interface for initiating the process and displaying generated MCQs.
  • popup.js: Script to handle user interactions and display results in the popup.

Step-by-Step Guide

Follow these steps to develop and test the Chrome extension:

1. Create manifest.json

The manifest.json file is the backbone of the extension, specifying its configuration.

  • Include permissions: "activeTab", "tabs", "storage" (optional), and the backend URL (e.g., "https://your-backend.com/*") for cross-origin requests.
  • Define the content script to run on all URLs ("<all_urls>") and list readability.js, dompurify.js, and content.js.
  • Specify background.js as the background script and popup.html as the popup.

2. Create content.js

This script extracts and cleans webpage content within the webpage’s context.

  • Use Readability.js to extract the main article content: let article = new Readability(document).parse();
  • Sanitize with DOMPurify: let cleanedContent = DOMPurify.sanitize(article.content);
  • Listen for messages from the background script and respond with the cleaned content.

3. Create background.js

The background script manages communication and backend requests.

  • Listen for messages from popup.js to initiate content extraction.
  • Send a message to content.js to extract content and make a POST request to the backend with fetch.
  • Return the MCQs to popup.js asynchronously, handling errors if the backend is unreachable.

4. Create popup.html and popup.js

The popup provides a user interface to trigger the process and display results.

  • In popup.html, create a button to start MCQ generation and a div for displaying results.
  • In popup.js, send a message to background.js on button click, show a loading indicator, and display MCQs upon response.

5. Implement Content Extraction

Use Readability.js to isolate the primary content, excluding extraneous elements like ads or navigation.

  • Handle cases where extraction fails (e.g., return an error if article is null).

6. Sanitize Content

Employ DOMPurify to remove potential XSS threats from the extracted content, ensuring security.

7. Send Content to the Server

Transmit the sanitized content to the backend securely.

  • Use fetch in background.js to send a POST request to https://your-backend.com/generate-mcqs.
  • Include the content in the request body as JSON: {"content": cleanedContent}.

8. Communication Flow Between Scripts

The scripts interact as follows:

  1. User clicks the button in the popup.
  2. popup.js sends a message to background.js with chrome.runtime.sendMessage.
  3. background.js requests content from content.js using chrome.tabs.sendMessage.
  4. content.js extracts and sanitizes content, sending it back to background.js.
  5. background.js sends the content to the backend, receives MCQs, and forwards them to popup.js.
  6. popup.js displays the MCQs or an error message.

9. Test the Extension

Ensure the extension works across various webpages.

  • Test with complex pages, empty content, and backend failures.
  • Verify error handling and user feedback in the popup.

10. Deploy the Extension

Package and distribute the extension.

  • Follow Chrome Web Store guidelines for privacy and security.

Additional Considerations

  • Privacy: Avoid sending sensitive data unless necessary; inform users of data usage.
  • Performance: Optimize extraction and minimize processing delays.
  • Security: Use HTTPS for backend communication; configure CORS correctly.
  • User Experience: Show a loading indicator in the popup during processing.

FastAPI Backend for MCQ Generation

Overview

This section outlines the development of a FastAPI backend that receives webpage content from the Chrome extension, processes it using the Groq API to generate MCQs, and returns them in a specified JSON format.

Requirements

Functional Requirements

  • Receive Webpage Content: Provide a POST endpoint (e.g., /generate-mcqs) to accept content in JSON format: {"content": "<text>"}.
  • Generate MCQs: Use the Groq API with two prompts: one to summarize content into key sentences, another to generate MCQs from those sentences.
  • Return MCQs: Send MCQs back to the extension in JSON format, adhering to the defined schema.

Technical Requirements

  • API Integration: Authenticate with the Groq API using an API key stored in environment variables.
  • Asynchronous Processing: Use async def for endpoints to handle API calls efficiently.
  • Security: Configure CORS to allow requests from chrome-extension://<extension-id>; secure API keys.
  • Validation: Use Pydantic to validate request and response data.

Implementation Details

Endpoint Example

from fastapi import FastAPI
from pydantic import BaseModel
import httpx
import os

app = FastAPI()

class ContentRequest(BaseModel):
    content: str

@app.post("/generate-mcqs")
async def generate_mcqs(request: ContentRequest):
    content = request.content
    if not content or len(content) > 10000:  # Example validation
        return {"error": "Invalid content length"}
    
    summary = await call_groq_api_summarize(content)
    mcqs = await call_groq_api_generate_questions(summary)
    return {"questions": mcqs}

Error Handling

Handle errors gracefully:

  • If the Groq API fails, return {"error": "API unavailable"}.
  • Validate content length and type to prevent processing issues.

Prompts for Groq API

Summarization Prompt

Task: Information Extraction for Question Generation
As a highly skilled AI, your expertise lies in meticulously analyzing text to identify and extract pivotal sentences. Your task involves the following steps:
1. Read the provided text thoroughly.
2. Identify and extract the most crucial sentences. These sentences should encapsulate the core facts, findings, or themes that are fundamental to the text's overall meaning.
3. Focus on clarity and conciseness. The extracted sentences should be self-contained and comprehensive, enabling the straightforward formulation of questions.
4. Ensure accuracy and relevance. The sentences selected should accurately represent the text's main ideas and be directly related to its central discussion.
5. Present the extracted sentences in a clear, organized manner, suitable for subsequent question development.
Your role is crucial in distilling the essence of the text into concise, informative segments that can serve as the basis for meaningful and relevant questions.
